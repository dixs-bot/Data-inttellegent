# AATIS Trading — Panduan Bahasa Indonesia

## Perubahan tampilan
- Seluruh navigasi dan teks utama dasbor telah diubah ke Bahasa Indonesia.
- Tema antarmuka diubah menjadi putih dengan latar abu-abu sangat muda, kartu putih, garis pembatas lembut, dan teks gelap agar lebih nyaman dibaca.
- Status agen, istilah trading yang umum, tabel, pengaturan, laporan, dan data contoh disesuaikan ke Bahasa Indonesia.
- Bahasa teknis seperti EMA, RSI, VWAP, ATR, BTC/USDT, Sharpe, dan Walk-Forward tetap dipertahankan karena merupakan istilah standar trading.

## Menjalankan aplikasi di Windows
1. Ekstrak ZIP ke folder kerja.
2. Buka folder `app` melalui Terminal / PowerShell.
3. Jalankan `npm install`.
4. Jalankan `npm run dev` untuk membuka mode pengembangan.
5. Buka `http://localhost:3000` di browser.

Untuk membuat build produksi, jalankan `npm run build`, lalu `npm start`.

## Catatan
- Salinan ini berisi perubahan bahasa dan tema pada frontend. Logika backend dan integrasi data tidak diubah sebagai bagian dari permintaan tampilan ini.
- Sebagian angka pada dashboard berasal dari data contoh (`mockData.ts`), bukan bukti performa trading langsung. Jangan gunakan angka contoh sebagai dasar keputusan transaksi.
- Aplikasi tetap untuk riset dan simulasi. Tidak ada jaminan profit dan tidak ada eksekusi order riil yang diaktifkan oleh perubahan ini.
